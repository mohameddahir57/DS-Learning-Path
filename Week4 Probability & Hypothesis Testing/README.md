# Week 4 - Probability & Hypothesis Testing

## Overview
This week is written in simple English with simple code, as requested. It teaches how to check if something you see in data is a **real pattern** or just **random chance** - one of the most useful and widely used skills in data science, business, and research. This week also finishes Phase 1 of the course with a Mini Project that uses everything learned across Weeks 1-4.

## What We Covered

**Day 1 - Probability Basics**
What probability means (a number between 0 and 1), simple rules for combining probabilities (AND = multiply, OR = add), and what a normal distribution (bell curve) looks like and means.

**Day 2 - Hypothesis Testing**
How to write a null hypothesis ("no real difference") and an alternative hypothesis ("there is a real difference"), what a p-value means, and how to run a simple t-test to compare two groups of numbers.

**Day 3 - Confidence Intervals & Significance**
What a confidence interval is (a range where the true answer probably sits, instead of one exact number), how to calculate one, and the difference between a Type I error (false alarm) and a Type II error (missed finding).

**Day 4 - A/B Testing + Mini Project 1 (Phase 1 Wrap-Up)**
What A/B testing is (comparing two versions of something, like two website designs) and how it's really just hypothesis testing applied to a real business question. Closed with Mini Project 1: a full walkthrough combining EDA, hypothesis writing, a t-test, and a plain-language conclusion.
