# Week 5 - ML Foundations

## Overview
Welcome to Phase 2! This week you built your first real machine learning models using Scikit-learn, the main Python library for machine learning. You learned the core workflow used for almost every model in this course: split the data, train the model (`.fit()`), make predictions (`.predict()`), and check the score (`.score()`).

## What We Covered

**Day 1 - ML Foundations**
What machine learning actually means (learning patterns from examples instead of hand-written rules), supervised learning, Scikit-learn, and why and how we split data into a training set and a test set before training any model.

**Day 2 - Linear Regression**
Your first real model. Linear Regression predicts a number (like a price or a salary) by fitting the best straight line through the data, then using that line to make predictions on new inputs.

**Day 3 - Logistic Regression**
Despite the name, this model is used for classification - predicting a category (like pass/fail) instead of a number. Covered the sigmoid curve, which turns a model's internal calculation into a probability between 0 and 1.

**Day 4 - Comparing Models + Week 5 Mini Challenge**
Reviewed when to use Linear vs Logistic Regression, learned how to fairly compare models (same data, same type of problem), and completed a mini challenge building both types of models on the same base dataset.
